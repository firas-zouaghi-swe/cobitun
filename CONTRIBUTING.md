# Contributing to CoBiTun

Thank you for contributing to CoBiTun! Your help makes this project better.

## How to contribute

1. Fork the repository.
2. Create a new branch from `main`.
3. Make your changes with clear commits.
4. Run existing tests and linting.
5. Open a pull request describing your changes.

## Coding standards

- Follow existing code style and TypeScript types.
- Run `npm run lint` before submitting changes.
- Include tests for new features and bug fixes.

## Pull request guidelines

- Use descriptive branch names.
- Keep PRs focused and small when possible.
- Provide a short summary and any relevant context.
- Link related issues if available.

## Reporting issues

- Create a bug report if the application behaves unexpectedly.
- Create a feature request for enhancements or new functionality.
