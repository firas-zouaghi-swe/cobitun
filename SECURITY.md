# Security Policy

## Reporting a Vulnerability

If you believe you have found a security issue in CoBiTun, please do not open a public issue.

Instead, use GitHub Security Advisories or contact the maintainers directly with details.

## What to include

- A clear description of the issue
- Steps to reproduce
- Impact and affected versions
- Any proof-of-concept code or logs

## Response

The maintainers will review the report promptly and respond with next steps.
