# Render Build & Runtime environment variable entries
# Instructions:
# - In Render dashboard, open your Web Service > Environment.
# - Add the Build Environment variables under "Build" (available during `npm run build`).
# - Add the Runtime Environment variables under "Environment" (available when the service runs).
# - Also add a Persistent Disk (Mount Path: /app/data, Size: 1 GB).
